## Plan : Context-Aware Provider (AST-Driven)

### 1. Analyse du problème

**Situation actuelle :**
- `context.ts` lit `method-index.json` → produit un SYMBOL MAP avec **signatures uniquement**
- `call-graph.cjs` identifie les callees, mais le résultat n'est **pas inclus dans le prompt**
- Claude reçoit des noms de méthodes + signatures → doit faire grep/find pour lire le code → coûteux

**Données disponibles dans `method-index.json` mais non exploitées :**
- `line` / `endLine` → localisation exacte du corps dans le fichier source → **snippets extractibles**
- `consumers[]` → liste des appelants → **graphe d'impact en cascade**
- `effects{}` → effets secondaires par méthode
- `description` (via annotation-cache) → JSDoc complet

**Modules de `lolve-cartography` disponibles mais non importés dans Claudicator :**
- `lib/context/method-search.cjs` → `MethodSearch.findRelevantMethods()` : moteur de scoring plus riche que `loadSymbolMap()`
- `lib/context/file-analyzer.cjs` → `FileAnalyzer.analyzeFile()` : métadonnées de fichier

### 4. Étapes de modification du code

#### Étape 1 — `context.ts` : Extraction des snippets

Ajouter une fonction `extractSnippets()` qui, pour chaque symbole sélectionné ayant `line` et `endLine`, lit les lignes correspondantes du fichier source dans `projectRoot` :

```diff
// context.ts

+/** Extrait les corps de méthodes depuis les fichiers sources. */
+function extractSnippets(
+    projectRoot: string,
+    selected: Array<{ key: string; method: MethodEntry }>,
+    maxSnippets = 5,
+    maxLines = 40
+): Record<string, string> {
+    const snippets: Record<string, string> = {};
+    let count = 0;
+    for (const { key, method } of selected) {
+        if (count >= maxSnippets) break;
+        if (!method.file || !method.line || !method.endLine) continue;
+        if (method.endLine - method.line > maxLines) continue; // snippet trop long → ignorer
+        try {
+            const abs = path.join(projectRoot, method.file);
+            const lines = fs.readFileSync(abs, "utf-8").split("\n");
+            snippets[key] = lines.slice(method.line - 1, method.endLine).join("\n");
+            count++;
+        } catch { /* silencieux */ }
+    }
+    return snippets;
+}
```

#### Étape 2 — `context.ts` : Graphe d'impact (consumers)

Ajouter une fonction `buildImpactGraph()` qui lit `consumers[]` de chaque méthode sélectionnée et retourne une map `clé → liste d'appelants` :

```diff
+/** Construit le graphe d'impact (qui appelle les méthodes sélectionnées). */
+function buildImpactGraph(
+    selectedKeys: string[],
+    allMethods: Record<string, MethodEntry>
+): Record<string, string[]> {
+    const graph: Record<string, string[]> = {};
+    for (const key of selectedKeys) {
+        const m = allMethods[key];
+        const consumers = (m as any)?.consumers as string[] | undefined;
+        if (consumers && consumers.length > 0) {
+            graph[key] = consumers;
+        }
+    }
+    return graph;
+}
```
