## Plan — Corrections artefacts/issues

### 1. Analyse du problème

**Trois dysfonctionnements identifiés :**

**A. Création d'issue → liste non rafraîchie**
Dans `IssueList.svelte:submitCreate()` (ligne 153), `await loadIssues()` est bien appelé après la création. Mais `GET /api/issues` interroge l'API GitHub (`getIssues(owner, repo)`) — si le cache Octokit ou GitHub lui-même tarde, la nouvelle issue n'apparaît pas. La solution propre est d'injecter directement l'issue créée dans `issues[]` depuis la réponse du POST, sans dépendre d'un re-fetch.

**B. Bouton "Générer" inconnu**
Localisé dans `ArtifactViewer.svelte:142` — section `plan-section`. Il appelle `generatePlan()` qui fait `POST /api/issue` pour produire un plan Claude associé à l'issue, stocké côté serveur. Ce bouton est invisible depuis la liste des issues, il n'est visible que quand une issue est sélectionnée dans le panneau Artefact. Il n'est pas intuitif car son rôle (générer un plan global ≠ planifier une task) n'est pas expliqué.

**C. Header redondant lors de la sélection d'une issue**
Dans `ArtifactViewer.svelte:96-103` :
```svelte
{#if $agentState.plan && $agentState.issue}
    Plan — #{$agentState.issue.number}
{:else if $agentState.issue}
    #{$agentState.issue.number}    ← écrase "Artefact"
{:else}
    Artefact
{/if}
```
Quand une issue est sélectionnée, le header passe de `"Artefact"` à `"#x"`. Or le titre complet `#{n} — titre` est déjà affiché dans le contenu (`issue-title`, ligne 109). Double information, et le titre sectionnel devient cryptique.

### 3. Stratégie

- **A** : Injection optimiste — après un POST réussi, construire un objet `Issue` depuis la réponse et l'insérer en tête de `issues[]`. Pas de suppression du `loadIssues()` existant (garde-fou).
- **B** : Renommer le bouton avec un label explicite ("Plan global") et ajouter un `title` descriptif. Option : le déplacer ou le masquer si jugé inutile — à confirmer par l'utilisateur.
- **C** : Conserver `"Artefact"` comme titre de section, permanent. Supprimer la logique conditionnelle qui remplace le titre par `#x`.
